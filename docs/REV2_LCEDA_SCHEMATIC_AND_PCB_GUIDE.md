## 一、Rev 2.7 整机三维堆叠、比例权衡与无干涉坐标（实测全正交 0 碰撞）

对照 **P3R 片头画面**与**剧场版平放实物参考图**，在保持底层全部实装硬件与结构壁厚（`>= 1.65mm`）的前提下，Rev 2.7 完成了多轮零信任回归清零（`06` 在 `Z>84.5mm` 将导轨与承托台肩全部退让至 `Y<=-2.05mm` 彻底避开 `-7.62mm` 焊点、`TF-01A` 按真实 `14.50mm` 深度＋`U1` 缩小/内偏焊盘消除冲突、补全 `J2/C14/R8/SW1..4` 全套网表、锁定 `K1@Z62..K4@Z38` 顺序，并修完固件全异常音频防卡死状态机）。

1. **板厚、L 型单框两板拼版与嘉立创 SMT 强制工艺边（必加！）**：2 层板，**`1.0mm` 板厚**，铜厚 `1oz`。在同一个完整矩形拼版外框（`< 100×100mm`）内，通过**内铣镂空槽 ＋ 邮票孔桥接筋**将 L 型 **`Main PCB（主体 17.60mm + 侧翼共 25.15 × 85.90mm）`** 与 **`6.0×32.0mm 按键子板`** 桥接为饱满矩形并仅勾 **经济型单面（Top Only）SMT**；**务必在两侧加上 `5mm` V-cut 可掰断工艺边（整框约 `35.15 × 96mm`），工艺边放 `4× Φ2.0mm` 定位孔、`3× Φ1.0mm` 光学定位 Mark 点须距外边沿 `>= 3.85mm`（或摆在主板上）以防 SMT 夹具压挡**。
2. **禁止颠倒的手工焊接装配顺序（`-M` 双排针磨平 + 剪断 `ME6217` + 双层 Kapton 零重叠）**：
   - 从嘉立创 SMT `CPL` 中移除 `J2` 及 `U1`（`J3` 在 Top `-X` 侧翼可让嘉立创机贴或随 Step 2 手焊）。
   - **Step 1（安全屏蔽 `ME6217` — 严禁用单支烙铁硬撬）**：`ESP32-S3-Zero(-M)` Type-C 口旁带有 `ME6217C33M5G` 五脚 LDO。若无热风枪，**千万不要用普通电烙铁堆锡硬拔（极易烫化 Type-C 塑料舌片或连带挑飞旁路 0402 电容）**——请直接用**精密水口斜口钳齐根剪断并挑开第 5 脚（`VOUT`，芯片独立一侧上角引脚）**（或到维修店用热风枪 5 秒吹下整颗芯片）。**⚠️ 剪挑完成后立刻用万用表二极管/电阻档测量开发板自身 `5V` 与 `3V3` 引脚，确认无导通/无残脚回弹后再上主板！**若使用 **`-M` 带排针版**：无需拆排针，插板前先在 `-M` 底部 `GP14`、`GP15` 焊盘上各点焊一根 `1.5cm` 细铜丝准备穿孔。
   - **Step 2**：将 `U1` 插入 `2×9P` 通孔（`-M` 版，2 根细丝同穿入 `GP14/GP15` 过孔，孔径 **`Φ0.95–1.0mm` / 焊盘 `Φ1.40mm` 或向内偏心椭圆使其外缘 `|X| <= 8.15mm`**）至主板 Top 面，从背面焊好 18 脚与 `GP14 / GP15`（`Φ1.4 / Φ2.0mm`），用斜口钳紧贴主板底面剪掉 `-M` 多余针脚后，**⚠️ 必须用 400~800 目细砂纸或小锉刀将 `±7.62mm` 双排所有伸出底面的金属针尖彻底磨平至与绿油齐平（消除 `-M` 针尖刺穿胶带及刮擦底座风险）**；若未机贴 `J3` 则一并在 `-X` 侧翼焊接。立刻用万用表测量 **`GP14 <-> Q3_G`** 与 **`GP15 <-> R21/R22 中点` 通断正常** 且 **相邻焊盘无连锡**。
   - **Step 3（全覆双层 Kapton + 避让冲突手焊 `J2`）**：用 **双层 `0.08mm` 耐高温 Kapton 绝缘胶带（共 `0.16mm`）完整覆贴磨平后的 `+7.62mm` 整列焊盘区（`X∈[+6.75,+8.40]`）与 `GP14/GP15` 孔背面**。接着手焊 Bottom 面的 **`J2 (TF-01A, C91145)`（`14.50mm` 深，`X∈[-6.20, +8.30], Z=90.8..105.6mm`）**：在立创 EDA 画板时须将 `J2` 右端外壳固定焊盘布置在 **`U1` 2.54mm 排针间隙外或外移至 `X=+8.45..+8.75mm` 板边/上下侧耳**（绝不与被胶带盖住的 `+7.62mm` 排针焊盘重合！），焊接时压紧外壳并焊牢 `-6.20mm` 信号脚与外围固定脚。**⚠️ 上电前必测**：万用表蜂鸣档测 **`J2` 金属外壳 (`GND`) 对右排 `GP7..GP13 / 3V3 / 5V` 全部绝对不导通**，并检查主板左右底沿 `0.60mm`（`|X|∈[8.20, 8.80]`）无溢出锡珠或高凸物。
   - **Step 4（总装推入顺序）**：**必须先将 `03` 背面药丸按键条从 `01` 内部落入背面按键槽并暂贴薄胶带防掉**，再接通 `551255` 锂电池与 `40~50mm` 留余量的 `30AWG` 按键子板线，将 `06` 内托组件**由顶部（`+Z -> -Z`）顺畅滑入 `01` 铝壳**，最后合上 `04` 与 `05` 并锁入背面 `M1.6` 螺丝（CNC 6061 铝请配 **头下螺纹长 `L = 2.0~2.2mm`（如 `M1.6×2` 规格，不含头厚）的 `M1.6` 机丝短螺丝**配合 `Φ1.30mm` 扩钻平底机丝锥攻牙；树脂 3D 打印直接旋入 `M1.6` 自攻）。
3. **上电与 3D 核对清单**：
   - **首次上电（不接电池，仅插 USB-C）实测**：先用万用表依次测 `3V3_ALWAYS = 3.3V ± 0.05V` → 固件拉低 `GP14` 后 `3V3_PERI ≈ 3.3V` → `U2` Pin 18 (`LDOO`) ≈ `1.8V` & Pin 5 (`VNEG`) ≈ `-3.3V` → `U5` Pin 12 (`HPVDD`) ≈ `1.8V`；全部电压正常再接锂电池并插拔 USB 确认 `LED1`（`-X` 翼 `J3` 下方露空处）亮灭正常；
   - 立创 EDA `3D 视图` 核对：**若用 `-M` 带排针版（2.54mm 底座 + 1.6mm 实板），确认 PCB 边缘在 `Y <= +4.04mm`、居中 Type-C 壳伸至 `Z≈109.5mm / Y<=+7.90mm`**（均已实测 `0` 碰撞）；裸板 PCB 边缘 `Y <= +1.50mm`；
   - `U1` 已画出 `2×9P` `Φ0.95-1.0mm / 盘 Φ1.40mm`（外缘 `|X| <= 8.15mm`）通孔（行距 `15.24mm`，`X=±7.62mm`），`J2`（`14.50mm` 深）摆在 `X∈[-6.20, +8.30]` 且右侧固定脚与 `+7.62mm` 排针无位置叠压；
   - 主板 PCB 在 `Z=108.2mm` 截止（Type-C 壳微伸至 `Z≈109.5mm` 仍留 `>=6.0mm` 余量），`J3` 对准 `(cx=-13.10mm, cy=+2.40mm)` 并已核对 `J3` PDF 定位柱 `NPTH` 与 Pin 4 接法，`-X` 侧翼低于 `Z=92.5mm` 保持 `17.60mm` 宽；
   - `SW1..SW4`（`Z=62/54/46/38mm` 对应 `K1..K4`）焊盘距 `6.0mm` 板边 `>= 0.5mm`，L 型拼版已用邮票孔筋补齐矩形并加 `5mm` V-cut 工艺边、`>= 3.85mm` 边距 Mark 点与定位孔，完整 `DRC 0 错误 0 飞线`！
