## 一、Rev 2 整体机械与板型方案（零干涉核对）

为同时解决 **2.25 寸屏（`17.90 × 62.50 × 2.36mm`）+ `601260` 电池（`60 × 12 × 6mm`）+ 背面 `03` 药丸按键（`Z = 46/54/62/70mm`）+ 顶部 `04` 深蓝帽耳机孔（`Z = 123mm`, `cx = -4.5mm`）** 的径向/轴向空间约束，Rev 2 主板与按键子板采用**“同板拼版（1.0mm FR-4，单面贴片，无额外开模/拼版费）”**：

```
Y 轴（径向剖面，圆管内径 Φ21.60mm / 底座06导槽宽 18.30mm）:
+9.10mm  ─── 02 亚克力/玻璃盖板 (t=1.0mm)
+8.10mm  ─── 2.25" ST7789P3 裸屏 (t=2.36mm, Z=24.5..87.0mm)
+5.74mm  ─── 屏幕背面与主板间净空 ≥ 3.7mm (绝缘茶色高温胶带隔离)
-1.00mm  ═══ 【主板 Top 面】 所有 SMT 贴片器件 + ESP32-S3-Zero (Z=24..119mm)
-2.00mm  ═══ 【主板 Bottom 面】 平整铺地铜，无任何底部贴片（仅极薄焊盘）
-2.10mm  ─── 601260 420mAh 锂电池 (12mm 宽 × 6mm 厚, Z=22..82mm)
-8.10mm  ─── 1.80mm 后盖按键仓净空
-9.90mm  ═══ 【按键子板 32×4×1.0mm】 SW1..SW4 (h=0.65mm) 总厚 1.65mm -> 正对 03 柱塞!
-12.0mm  ─── 01 铝合金外壳背面 / 03 齐平药丸按键表面
```

### 拼版外形尺寸（总面积远小于 100×100mm，享 ¥20 基础板费）
1. **主板（Step 阶梯长条，总长 `94.0mm` × 厚 `1.0mm`）**：
   - **主区（`Z = 25 .. 91mm`，长 `66.0mm` × 宽 `17.60mm`）**：穿入 `06` 内托 `18.30mm` 滑槽；前段（`Z = 25..68mm`）仅放矮件 `≤ 2.0mm`（`J4`、`U2`、`U3`、`U4`、`Q1`、`D1/D2`、`R/C`）；中上段（`Z = 68..91.5mm`）焊接 `Waveshare ESP32-S3-Zero`，**Type-C 口朝上（`+Z`）齐平 `Z = 92mm` 处，拔掉 `04` 深蓝帽即可插线充电/刷机！**
   - **上延舌区（`Z = 91 .. 119mm`，长 `28.0mm` × 宽 `15.80mm`）**：穿入 `04` 深蓝帽内孔（`Φ18.6mm`）；顶端（`X = -4.5mm`, `Z ≈ 107..121mm`）放 `J3 PJ-320D-SMT` 3.5mm 耳机座，下方可放 `J2 TF-01A`（说明见第四节）。
2. **按键子板（通过 2~3 个邮票孔或 V-Cut 挂在主板旁一起下单，`1.0mm` 同厚，到手掰开即可）**：
   - 尺寸 **`32.00 × 4.00mm`**，Top 面等距 `8.00mm` 放置 `SW1, SW2, SW3, SW4`（中心坐标 `4.0, 12.0, 20.0, 28.0mm`），完美对齐 `01/03` 壳体的 `Z = 46, 54, 62, 70mm` 四个背面按键孔；一端留 **5 个 `1.0mm` 焊盘**（`K1, K2, K3, K4, GND`），用 5 根 `30AWG` 超细硅胶线绕过电池侧面连回主板对应焊盘。

> [!TIP]
> **关于 `04` 顶部耳机孔与 `PJ-320D` 的同心度提醒**：
> 当主板 Top 面位于 `Y = -1.00mm`、`PJ-320D`（体高 `5.0mm`）正面贴装时，3.5mm 插孔圆心在 **`Y = -1.00 + 2.50 = +1.50mm`**。若使用当前 CAD 模型（`04` 耳机开孔中心在 `Y = 0.0mm`，孔径 `Φ7.6mm`），大直径耳机插头外壳可能顶到 `+Y` 孔壁 `~0.7mm`。你有两种零痛解：
> - **方案 A（推荐）**：后续下 CNC 单时将 [generate_cad_models.py](file:///C:/Users/wjwpo/.gemini/antigravity/scratch/persona3_mp3/cad/scripts/generate_cad_models.py#L315) 中 `04` 耳机孔偏移改为 **`cy = +1.50mm`**（与正面 SMT 完全同心，最牢靠）；
> - **方案 B**：不改 CAD，改为把 `PJ-320D` 买/换为**沉板式 3.5mm 耳机座**，使插孔中心落回 `Y ≈ 0mm`。

### 4. 2.25 寸 TFT 屏接口 & 背光驱动 (`J4 FPC-05F-8PH20`, `Q1 AO3401A`, `R2..R4, R9, R10, C11, C15`)
因 8PIN 裸屏内部已将背光负极 `LEDK` 接入 `Pin 2 GND`，无法使用低边 NPN 三极管（`S8050` 会损失 0.7V 导致无法点亮）。Rev 2 改用超低内阻 **高边 P-MOS `AO3401A`（`C15127`）**（固件 [main.cpp](file:///C:/Users/wjwpo/.gemini/antigravity/scratch/persona3_mp3/firmware/src/main.cpp#L73) 已同步修改 `cfg.invert = true`，`GP44` 输出低电平时点亮背光）：

| | **`G` (Gate, 脚 1)** -> `TFT_BL_GATE` -> 经 `R10 (1k)` 接 `GP44` | **同时在 `TFT_BL_GATE` 与 `3V3` 间并接 `R4 (10k)` 上拉！确保开机瞬间背光不闪** |
| | **`D` (Drain, 脚 3)** -> 经 `R9 (10Ω)` 接 **`TFT_LEDA`** | 导通压降 < 5mV，全亮度驱动 `If≈40mA` |

> [!CAUTION]
> **下单前必检：`J4` `Pin 1 ~ Pin 8` 线序防镜像检查！**
> 1. 屏幕正面（玻璃面 `+Y`）朝向自己、排线向下时：丝印 **`Pin 1 (LEDA)` 在左，`Pin 8 (CS)` 在右**，金手指在正面（玻璃侧）。
> 2. 按厂家《FPC弯折示意图》将排线**向屏幕背面（`-Y`）反折 180° 贴于屏背**：此时金手指**朝向背面（正对 PCB Top 面）**，适合 **`C2856800` 下接型（Bottom Contact）** FPC 座。
> 3. **翻折后俯视屏幕背面**（假设屏幕竖放、排线端朝下，折叠排线尖端指向上方插入 PCB 的 `J4`）：此时在世界坐标系 `-X`（你看着 PCB Top 面时、排线从下往上插进 `J4` 的 **左侧**）依然对应 **屏幕原 `Pin 1 (LEDA)`**！
> 4. 请在立创 EDA 打开 `C2856800` 封装 3D 预览，把 `J4` **开口朝下（`-Z`）** 摆在 PCB Top 面，确认 PCB 封装中 **`Pin 1` 位于开口的左端**（若封装 Pin 1 在右，则直接将屏幕旋转 180° 贴装或改在电路中反转 `1..8` 次序，**切勿盲目连线！**）。

### 5. MicroSD 卡槽 (`J2 TF-01A, C91145`) & 背面 4 颗药丸按键 (`SW1..SW4`)
- **`J2 (TF-01A)`**:
  - `Pin 1 (DAT2)`: `NC`
  - `Pin 2 (CD/DAT3)`: `SD_CS` (`GP10`)，并用 `R8 (10k)` 上拉到 `3V3`
  - `Pin 3 (CMD)`: `SD_MOSI` (`GP11`)
  - `Pin 4 (VDD)`: `3V3` + `C14 (100nF -> GND)`
  - `Pin 5 (CLK)`: `SD_SCK` (`GP12`)
  - `Pin 6 (VSS)` + 外壳屏蔽脚 (`9/10/11/12`): `GND`
  - `Pin 7 (DAT0)`: `SD_MISO` (`GP13`)
  - `Pin 8 (DAT1)`: `NC`
  - `CD 卡检测脚`（若该封装有独立微动检测脚）: `NC`
- **背面 4 颗按键（子板 `SW1..SW4` `TS263065A C49023761`，均低电平有效，触发 `ESP32-S3` 内部上拉）**:
  - `SW1` (`Z = 46mm`): 一端接 `KEY_1` (`GP1`)，另一端接 `GND`
  - `SW2` (`Z = 54mm`): 一端接 `KEY_2` (`GP2`)，另一端接 `GND`
  - `SW3` (`Z = 62mm`): 一端接 `KEY_3` (`GP3`)，另一端接 `GND`
  - `SW4` (`Z = 70mm`): 一端接 `KEY_4` (`GP7`)，另一端接 `GND`

## 四、立创 EDA PCB 布局与布线核心要点

1. **板层与板厚**：2 层板，**FR-4 板厚务必选 `1.0mm`**，铜厚 `1oz`，无铅喷锡/沉金皆可（喷锡性价比最高）。
2. **器件分区建议（从下至上 `Z = 25mm -> 119mm`）**：
   - **`Z = 25 .. 46mm`（低区，限高 `≤ 2.0mm`）**：`J4 (FPC-05F-8PH20)` 放最下方附近（配合屏幕反折后 `~21.8mm` 长度直接平顺插入！），旁边放 `Q1, R9, R10, R2, R3, R4, C11, C15`、`U3 (TP4056) + R1 + D1/D2 + LED1 + R11`、`U4 (RT9013-33GB) + C7/C8`，底边留 `J5`（`VBAT+ / GND` 电池线焊盘）和 5 个 `1.0mm` 子板飞线焊盘。
   - **`Z = 46 .. 68mm`（音频独立干净区，限高 `≤ 2.0mm`）**：`U2 (PCM5102APWR)` + `C1..C6` + `R5/R6/R7` + `C9/C10`。**走线尽量缩短在 8mm 内，电容紧贴 IC 管脚**；远离 `ESP32` 天线区域！
   - **`Z = 69 .. 92.5mm`（主控焊接区）**：横跨 `15.24mm` 双排焊盘放 `U1 (ESP32-S3-Zero)`，**Type-C 口朝 `+Z` 指向上方 `Z = 92.5mm`**（即 `01` 与 `04` 接缝处，方便日后拔掉顶盖直插 USB 拷歌/充电）。注意 S3 陶瓷/PCB 天线端避免紧贴大面积铺铜或走高电流电源线。
   - **`Z = 93 .. 119mm`（上延舌区，宽度收敛到 `15.80mm`，伸入 `04` 深蓝帽内）**：
     - 顶端 `X = -4.5mm`, `Z ≈ 106..120mm` 放 `J3 (PJ-320D-SMT)`（插座口朝 `+Z` 对齐顶面耳机孔）。
     - `Z = 93 .. 107mm` 放 `J2 (TF-01A)`：若与 `PJ-320D` 上下错不开插卡口，可将 `TF-01A` 开口朝向 **侧边或下方空档（插好 32GB 卡后装入，平时用 `MODE_USB_MSC` 模式通过 Type-C 直接电脑传歌，无需频繁插拔 TF 卡！）**，这样依然保持全主板 **100% 单面（Top Only）嘉立创机贴**，不用手工焊 9 个密脚！
3. **线宽与设计规则（DRC）**：
   - 电源主干道（`USB_5V`, `VSYS`, `VBAT`, `3V3`, `LEDA`）：**`0.5mm (20 mil)` ~ `0.6mm`**
   - 普通信号线（SPI / I2S / GPIO / 按键）：**`0.20mm (8 mil)` ~ `0.25mm`**，线距 `≥ 0.20mm`
   - 过孔（Via）：外径 `0.50mm` / 孔径 `0.30mm`
   - **Bottom 层全板大面积铺 `GND` 铜皮**，并在 Top 层空余处同样铺 `GND` 并多打地过孔（Stitching Vias），`TP4056` 散热焊盘正下方打 4~6 个 `0.3mm` 地过孔导热。
4. **嘉立创下单流程**：
   1. 立创 EDA 完成 `DRC 全部通过（0 错误，0 飞线）`；
   2. 导出 Gerber（`生成 PCB 制板文件`）+ 导出 BOM + 导出坐标文件（`CPL`）；
   3. 嘉立创下单助手上传 Gerber -> **板厚选 `1.0mm`**，颜色随心（建议哑光黑或沉金蓝/绿） -> 勾选 **`SMT 贴片`** -> 选 **`经济型 - 仅贴单面（Top）`** -> 上传刚刚生成的 BOM & 坐标文件，在**实时 3D 元件匹配预览图**里逐个确认 `PCM5102A` 一脚小圆点、`TP4056` 方向、`1N5819WS` 阴极丝印与 `J4` 开口方向无误后提交！
