## 四、立创 EDA PCB 布板要点与下单核验

1. **板厚与工艺**：2 层板，**`1.0mm` 板厚**，铜厚 `1oz`，`Main PCB (Top)` 与 `6×32mm 按键子板 (+5mm 工艺边)` 勾**经济型单面（Top Only）SMT**。
2. **手工补焊 `J2` / `J3`（Bottom 面）**：从提交给嘉立创 SMT 的 `CPL` 中移除 `J2` 与 `J3`，避免触发高额双面贴片及换料费；收到板子后用烙铁先焊好 `J2 (TF-01A)` 和 `J3 (PJ-320D-SMT)`，再焊 `ESP32-S3-Zero`（先吹掉 `ME6217`）、`601260` 电池线、及 `5` 根 `30AWG` 按键子板线。
3. **3D 验证清单**：导出 Gerber 前在立创 EDA `3D 视图` 中逐一确认：
   - `Z=108..120.5mm` 右侧及 `+Y` 区域全空（USB-C 插头可直穿）；
   - `J3` 中心坐标严格对准 `(-3.50mm, 相对外壳 cy=-3.60mm)`；
   - `SW1..SW4` (`3.0×2.6mm`) 焊盘距 `6.0mm` 板边 ≥ `0.5mm`；
   - 完整 `DRC 0 错误 0 飞线`！
