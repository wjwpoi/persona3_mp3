## 一、Rev 2.4 整机三维堆叠、比例权衡与无干涉坐标（实测全正交 0 碰撞）

对照 **P3R 片头画面**与**剧场版平放实物参考图**，在保持底层全部实装硬件与结构壁厚（`>= 1.65mm`）的前提下，Rev 2.4 全面清零了独立 Pre-Production Review 中的全部 Blocker（隔板、双止口裂壳、侧兜转角干涉、闭环止口碰撞、M1.6 缩孔）与重大风险：
- **比例权重（`D = 24.0mm`）**：`05` 半球底 `18.0mm (0.75D)` : `01` 银主体 `74.5mm (3.10D)` : `04` 深色筒身 `25.0mm (1.04D)`（**帽/银比 `25.0 / 74.5 = 0.336`**，精确落于剧场版实物 `0.327` 与 P3R 片头 `0.350` 正中间），加上加厚加固顶端居中挂绳耳后总长 **`122.0mm`**。
- **表面氧化与挂绳参考**：`01 + 05` 推荐采用**暖香槟钛银磨砂阳极氧化**，`04` 采用**深枪灰 / 亮黑钛或深海蓝阳极氧化**，配短黑手机绳扣＋天青色（Cyan）织带颈绳即可高度还原剧场版平放/胸前观感。

所有部件坐标均已与 [generate_cad_models.py](../cad/scripts/generate_cad_models.py) 逐点切片与角包络交叉验证（主筒内径 `Φ21.40mm` / `r=10.70mm`，底座 `06` 内托在 `Z>84.5mm` 退让至 `Y <= -0.15mm`）：

## 四、立创 EDA PCB 布板要点、单框两板拼版与不可逆防呆装配顺序

1. **板厚与单框两板拼版工艺（`O-03` 优化）**：2 层板，**`1.0mm` 板厚**，铜厚 `1oz`。只需在同一个矩形外框（`< 100×100mm`）内，通过**内铣镂空槽 ＋ 邮票孔桥接**将 **`Main PCB（含 -X 侧翼，外框 85.90 × 25.15mm）`** 与 **`6.0×32.0mm 按键子板`** 合拼为一单（**2 块板，取消音频子板且零多拼版加价**），全部仅勾 **经济型单面（Top Only）SMT** 并共用一张钢网；`J3 (PJ-320D-SMT)` 在 Top `-X` 侧翼可直接机贴或随 `U1` 并排手焊。
2. **禁止颠倒的手工焊接装配顺序（解决 `GP14/GP15` 与 `J2` 盲焊干涉）**：
   - 从嘉立创 SMT `CPL` 中移除 `J2` 及 `U1`（`J3` 若未选中机贴也可随 Step 2 一并手焊）。
   - **Step 1**：热风枪拆除 `ESP32-S3-Zero`（无排针版）自带的 `ME6217C33M5G` 五脚 LDO。
   - **Step 2**：贴焊 `U1 (ESP32-S3-Zero)` 周圈半孔至主板 Top 面，并**透过主板预设的 `Φ1.4mm` 镀铜过孔（`Φ2.0mm` 焊盘，保 `0.54mm` 阻焊桥）补焊底部 `GP14` 与 `GP15` 焊盘**；若未机贴 `J3`，可一并在 `-X` 侧翼 Top 面焊接 `J3 (PJ-320D-SMT)`；立刻用万用表测量 **`GP14 <-> Q3 栅极`** 与 **`GP15 <-> R21/R22 分压中点` 通断正常** 且 **对相邻底部 `2.54mm` 焊盘无桥接短路**。
   - **Step 3**：在 `J2 (TF-01A)` 下方主板 Bottom 面区域及 `GP14/GP15` 孔背面**平贴一条 `0.08mm` 耐高温 Kapton 绝缘胶带**，最后再手工焊接 Bottom 面的 **`J2 (TF-01A)`（开槽严格朝 `+X`）**，并确认主板左右两侧底沿 `0.60mm`（`|X|∈[8.20, 8.80]`）无下垂锡珠或突出器件以贴合 `06` 内托承托台肩。
   - **Step 4**：接通 `551255` 锂电池与 `30AWG` 按键子板线，将内托组件**由顶部（`+Z -> -Z`）顺畅滑入 `01` 铝壳**（`-X` 侧翼停于 `Z=92.8mm` 高于 `01` 顶缘 `92.5mm` 不干涉），最后套上 `04` 深色帽盖、从底部合上 `05` 半球盖并拧入背面隐藏 `M1.6` 螺丝。
3. **3D 验证与实物核对清单**：导出 Gerber 前在立创 EDA `3D 视图` 与实物复测中逐一确认：
   - 用卡尺复测手头无排针版 `ESP32-S3-Zero` 在 `|X|=8.5..9.0mm` 两侧边缘最大高度 `<= +4.78mm`（居中 USB-C 可达 `+5.20mm`），焊接时勿在两侧加高焊锡以免擦碰 `04` `R10.20mm` 内腔；
   - 主板在 **`Z = 108.2mm`** 彻底截止，`Z > 108.2mm` 无任何铜皮或器件（取帽后市售 `12.0×6.4mm` USB-C 插头可无阻直插）；
   - **`J3` 中心坐标严格对准 `(cx = -13.10mm, cy = +2.40mm)`**（距 `S3-Zero` `X=-9.00mm` 边缘焊盘留隙 `0.60..0.90mm`），且已从官方 PDF 核对 `J3` 底部 `2` 颗塑料定位柱非金属化孔及 Pin 4 CTIA/Switch 接法；
   - `-X` 侧翼下缘自 **`Z = 92.80mm`** 向外探出，低于 `Z = 92.50mm` 保持 `17.60mm` 宽度且 Bottom 边沿 `0.60mm` 无凸出器件，确保从顶部无阻滑入 `01` 并平座于 `06` 承托台肩；
   - `SW1..SW4` (`3.0×2.6mm`) 焊盘距 `6.0mm` 板边 ≥ `0.5mm`；
   - 完整 `DRC 0 错误 0 飞线`！
