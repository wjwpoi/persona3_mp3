## 二、 方案 A 到手 10 分钟「插线即用」傻瓜式拼装步骤

```
[XIAO ESP32-S3 核心板 (17.5x21mm)]
  ├── 3V3 / GND / D4(SDA) / D5(SCL) ──> [0.91寸 128x32 I2C OLED 模块 (12x38mm)]
  ├── 5V / GND / D6(TX) / D7(RX)    ──> [DFPlayer Mini / PCM5102A 音频+TF卡模块] ──> [顶部 3.5mm 耳机孔]
  ├── D0 / D1 / D2 / D3             ──> [右侧 4 颗胶囊按键 (播放 / 下一首 / 上一首 / 循环)]
  └── BAT+ / BAT-                   ──> [401235 / 501240 3.7V 锂电池]
```

1. **第一步：烧录 P3R 开场动画固件（1 分钟）**
   - 用普通手机 USB Type-C 数据线将 `XIAO ESP32-S3` 插入电脑 USB 口。
   - 打开本仓库 [`firmware/`](../firmware/) 工程点击上传，立刻点亮：
     - 开机 `"H E L L O !"` 整体平滑浮现动画；
     - `"▶ Burn My Dread / 01:36 / ↻ [🔋] / VOL ||||||"` 播放主界面；
     - 切歌时全屏所有元素上下联动翻页滚动动画！
2. **第二步：对插 4 个成品模块（3 分钟）**
   - 用母对母软排线按上方接线图把 `0.91寸 OLED`、`音频/TF卡模块`、`4颗侧按键` 插到 `XIAO ESP32-S3` 对应排针上。
3. **第三步：推入 `06` 免焊内胆与 `01` 主圆管（3 分钟）**
   - 将 `0.91寸 OLED` 屏幕朝外卡在 `06_internal_zero_solder_sled` 正面窗口槽；
   - 将锂电池、音频模块和 `XIAO ESP32-S3`（Type-C 口朝下对准底盖方向）塞入内胆背槽；
   - 将 `03_side_4_button_strip_silver`（右侧 4 联按键条）从 `01` 主圆管内部穿过右侧 4 个椭圆通孔，再把内胆整体推进 `01` 主圆管！
4. **第四步：嵌装 `02` 屏幕视窗与 `04/05` 顶底盖（3 分钟）**
   - 将 `02_oled_smoked_lens`（8001 半透明视窗）卡入 `01` 正面沉台；
   - 顶部套上 `04_top_navy_collar_lanyard_cap`（穿入钥匙圈挂绳与耳机插孔），底部套上 `05_bottom_rounded_dome_cap_silver`（平时隐藏 Type-C 口与 TF 卡槽，拔下底盖即可插线充电或换卡）！
