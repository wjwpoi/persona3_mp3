## 二、 嘉立创 PCB + SMT 贴片下单步骤（3 分钟完成）

1. 打开 **[嘉立创下单助手](https://www.jlc.com/)** 或网页端「PCB + SMT 打样」。
2. **上传 Gerber 文件**：点击上传本仓库 [`hardware/gerber_and_smt/Gerber_JLCPCB_Persona3_MP3_4Layer.zip`](../hardware/gerber_and_smt/Gerber_JLCPCB_Persona3_MP3_4Layer.zip)。
   - **板子层数**：自动识别为 `4层`，尺寸 `68.0 × 14.4 mm`
   - **板厚**：强烈建议选 **`1.0 mm`**（确保装入 Φ16.8mm 内径圆管时为电池和屏幕留出最充裕的净空）
   - **阻焊颜色**：`哑光黑` 或 `黑色`
   - **焊盘喷镀**：`沉金`（保证 `0.5mm` 间距 FPC 座和 `ESP32-PICO` 焊盘极致平整）
3. **勾选「需要 SMT 贴片」**：
   - **贴片数量**：选择 `2 片`（1片主力使用，1片备用）
   - **上传 BOM 清单**：上传 [`hardware/gerber_and_smt/BOM_JLCPCB_Persona3_MP3.csv`](../hardware/gerber_and_smt/BOM_JLCPCB_Persona3_MP3.csv)
   - **上传坐标文件 (CPL)**：上传 [`hardware/gerber_and_smt/CPL_PickAndPlace_JLCPCB_Persona3_MP3.csv`](../hardware/gerber_and_smt/CPL_PickAndPlace_JLCPCB_Persona3_MP3.csv)
4. **预览确认**：在嘉立创 DFM 3D 预览界面确认 `U1 (ESP32)`、`U2 (PCM5102A)`、`J1 (Type-C)`、`J3 (耳机座)`、`J4 (FPC座)` 极性无误后直接提交付款。

### 1. 金属机身件（嘉立创 CNC 机械智造）
将 [`cad/stl/`](../cad/stl/) 下的以下 4 个模型上传至嘉立创 CNC（或导出 STEP 格式上传）：
- `01_cnc_main_shell_6061_silver.stl`（主圆管外壳，Φ20.0mm × 58.0mm）
- `03_rotary_jog_crown_knurled.stl`（顶部滚花旋钮环，Φ20.0mm × 10.0mm）
- `04_top_cap_headphone_port.stl`（顶部 3.5mm 耳机口端盖）
- `05_bottom_lanyard_cap.stl`（底部一体式挂绳环底盖）
- **材料与表面处理**：选择 **铝合金 6061** -> **喷砂 + 阳极氧化（本色银 / 哑光银）**。

### 2. 隐藏式 OLED 滤光视窗与免焊内胆架（嘉立创 3D 打印）

## 四、 到手 5 分钟「零焊接」傻瓜式组装教程

收到嘉立创寄来的包裹后，你只需要准备一把小十字螺丝刀，**全程不需要电烙铁**：

1. **第一步：插接 OLED 屏幕排线**
   - 用指甲轻轻挑起主板正面 `J4`（14Pin FPC 座）的黑色翻盖锁扣。
   - 将 `0.91寸 128×32 OLED` 裸屏的软排线金手指朝下插入 `J4`，按平黑色锁扣锁紧。
   - 将 OLED 玻璃屏平贴在 `06_internal_zero_solder_sled`（内胆支架）正面上方的屏幕托槽内（屏幕自带背胶可直接粘牢）。
2. **第二步：插接锂电池端子**
   - 将 `501240 (300mAh)` 锂电池放入内胆支架底部的电池仓槽内。
   - 将电池自带的 `JST-SH 1.0mm 2P` 小白插头直接对准主板背面的 `J5` 母座推入卡紧（零焊接！）。
3. **第三步：固定主板与旋钮环**
   - 将主板卡入内胆支架导轨，使顶部的 `SLLB510100` 三向拨杆开关对准 `03_rotary_jog_crown_knurled`（金属滚花旋钮环）内部的拨叉槽。
4. **第四步：推入铝合金圆管并锁紧端盖**
   - 将粘好 `02_oled_smoked_lens`（半透黑弧面视窗）的 CNC 铝合金主壳体套在支架外侧。
   - 盖上顶部耳机盖（`04`）和底部挂绳盖（`05`），拧入 2 颗 `M1.6 × 4mm` 沉头小螺丝锁固。
5. **第五步：刷入固件与拷歌**
   - 用 USB Type-C 数据线连接电脑，在 VS Code + PlatformIO 中打开本仓库 [`firmware/`](../firmware/) 目录，点击 `Upload` 一键烧录固件。
   - 将 P3 / P3R 原声带 MP3 文件命名为 `01.mp3`, `02.mp3` ... 拷入 MicroSD 卡插入底部卡槽，或拨动开关连接手机蓝牙 `P3R Walkman S.E.E.S.`，即可佩戴铁三角耳挂耳机（如 ATH-EM700 / EQ300M）开始播放！
